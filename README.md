# José Antonio Garrido

I build open-source tools so many AI coding agents can work in parallel on your own machine and accounts, without repeating each other's tests, fighting for memory or leaving you guessing which one needs you.

## What I build

- **[claudio](https://github.com/yeyo11/claudio)** runs Claude Code as a self-hosted service: a REST API, a web UI and a board where agents work in parallel, each in its own git worktree, through the official CLI and your own Claude login. One container. TypeScript, MIT.
- **[Sluice](https://github.com/josegarridodigio/sluice)** puts the builds, tests and heavy commands of every AI agent on a Linux machine in one queue, under a shared CPU and memory budget, and runs each check once per git tree. On one of my machines it saved 19 h 24 min of runs in 6 days. Rust, MIT. [How it works](https://josegarrido.dev/en/sluice-shared-queue-so-your-agents-stop-repeating-tests/?utm_source=github&utm_medium=referral&utm_campaign=profile-readme)
- **[Shipcast](https://github.com/yeyo11/shipcast)** turns a GitHub release into an article and one post per channel, and publishes each one once you approve it. TypeScript, MIT.
- **[google-docs-mcp](https://github.com/yeyo11/google-docs-mcp)** explains a Google Doc's comments to your AI assistant: who wrote each one, on which text, and the whole reply thread. Read-only, on npm as `@yeyo11/google-docs-mcp`.

I write each one up the day it ships, with the commands and the numbers.
